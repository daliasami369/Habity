# 🌿 Habity Dashboard

A modern and responsive Habit Tracker Dashboard built using HTML, CSS, Bootstrap, and JavaScript.

## 📌 Overview

Habity is a clean and user-friendly dashboard that helps users monitor their daily habits and track their progress through an intuitive interface. The design is fully responsive and optimized for desktop, tablet, and mobile devices.

## ✨ Features

- Responsive design for all screen sizes
- Modern and clean user interface
- Habit progress cards
- Daily and weekly statistics
- Sidebar navigation
- Interactive buttons and components
- Smooth layout using Bootstrap Grid
- Organized and reusable code structure

## 🛠️ Technologies Used

- HTML5
- CSS3
- Bootstrap 5
- JavaScript (ES6)

## 🚀 Getting Started

1. Clone the repository

```bash
git clone https://github.com/daliasami369/Habity.git
```

2. Open the project folder.

3. Run `index.html` in your browser.
